GTA VI COUNTDOWN — projeto Android inicial

O que faz:
- Mostra uma faixa flutuante no topo da tela com dias, horas, minutos e segundos.
- Atualiza a cada segundo.
- Contagem configurada para 19/11/2026 às 00:00 no horário de Brasília.
- Inclui botões para ativar e desativar a faixa.

IMPORTANTE:
- Este arquivo ZIP contém o CÓDIGO-FONTE, não um APK pronto para instalar.
- Para gerar o APK é necessário abrir o projeto no Android Studio, deixar o Gradle sincronizar e compilar.
- Na primeira ativação, o Android pede a permissão “Exibir sobre outros apps”.
- Android pode restringir serviços em segundo plano; alguns aparelhos podem exigir permitir execução em segundo plano.
- A faixa é uma sobreposição logo abaixo da barra de status, não texto inserido dentro da barra de status do sistema.
- O logo oficial do GTA VI não foi incluído. O nome “GTA VI” é usado como texto para evitar distribuir arte oficial no projeto.
